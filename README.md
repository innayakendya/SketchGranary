# SketchGranary

Syncs digital sketch assets with multiple repositories in real-time, ideal for design teams and freelancers.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchGranary.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SketchGranary is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
